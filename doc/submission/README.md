# Lab1：SVG 命令行编辑器

Git 仓库地址：<https://github.com/zero0307/svg-editor-cli>

仓库已公开，可直接查看代码和提交历史。

提交版本：[final 标签](https://github.com/zero0307/svg-editor-cli/tree/final)

实验文档：[doc/README.md](https://github.com/zero0307/svg-editor-cli/blob/final/doc/README.md)

实验文档包含架构方案、PlantUML 架构图、AI 协作过程记录、一致性自查和质量保证说明。代码的分步开发记录可在仓库提交历史中查看。

使用 Node.js 22 或更新版本，在克隆的仓库根目录执行：

```sh
npm ci
npm run check
npm run verify:visual
```

启动命令行编辑器：

```sh
npm run cli
```
